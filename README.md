# CampusEats Task Tracker

Small task-tracking example for SE3090 Lab 08. The repository demonstrates a GitHub Flow workflow, issue tracking, CI checks, and secure code-quality practices.

## Project structure

- `src/tasks.js` - task list and validated order-total calculation
- `.github/workflows/ci.yml` - GitHub Actions CI workflow

## Development workflow

Changes are developed on short-lived feature or chore branches, reviewed through pull requests, and merged into `main` only after the required checks pass.
